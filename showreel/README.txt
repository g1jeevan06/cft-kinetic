Put the Craftech360 showreel video in this folder, named exactly:

    showreel.mp4

It plays in the museum's "Our showreel" window (at the lobby globe), both online and when the museum is opened
from disk. Use an H.264 .mp4 so every browser can play it. CFT-Kinetic-Museum.html (the single-file edition next
to the online folder) plays this same file. Without a file here, the window falls back to YouTube.
